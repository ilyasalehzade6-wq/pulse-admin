# 🎛️ پالس ادمین

پنل مدیریت SaaS «پالس مدیریت» — برای مدیریت مشتری‌ها و لایسنس‌ها.

## 🚀 اجرا

1. فایل `js/config.js` را باز کن
2. `SUPABASE_URL` و `SUPABASE_KEY` را تنظیم کن
3. `ADMIN_PHONES` را با شماره‌ی خودت ست کن
4. با Live Server یا وب سرور باز کن
